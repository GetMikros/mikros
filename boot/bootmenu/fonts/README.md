# Fonts

`Inter-Regular.ttf` and `Inter-SemiBold.ttf` are the static TTF files from
`extras/ttf/` of the Inter 4.1 release
(https://github.com/rsms/inter/releases/tag/v4.1, `Inter-4.1.zip`, SHA-256
`9883fdd4a49d4fb66bd8177ba6625ef9a64aa45899767dde3d36aa425756b11e`),
unmodified. They are licensed under the SIL Open Font License 1.1 in
`OFL.txt`.
